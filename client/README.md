# Aether Clinic - Frontend 🛰️

The frontend of Aether Clinic is a high-tech, futuristic web application built with **React** and **Vite**. It focuses on providing a "Professional but Crazy" sci-fi aesthetic with smooth animations and interactive components.

---

## 🚀 Teck Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Vanilla CSS
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **State Management**: React Hooks (`useState`, `useEffect`)
- **API Client**: [Axios](https://axios-http.com/)
- **Visual Effects**: Canvas-based Neural Maps, Glitch effects, 3D Tilt transforms.

---

## 🏗️ Core Components

### 1. Holographic Dashboard
- **HUD Overlay**: Provides a futuristic frame with scrolling data tickers.
- **Neural Map**: An interactive canvas visualization of a neural network.
- **Flashlight Hero**: A mouse-tracking reveal effect on the main slogan.

### 2. 3D Consultation Carousel
- Uses a custom 3D carousel logic to navigate through medical specialists.
- Holographic card designs with "Status: Active" pulsing indicators.

### 3. AI Chatbot ("The Session")
- A glassmorphic command center interface.
- Real-time interaction with the local LLM.
- **Glitch Reveal**: AI responses appear with a data-decryption effect.

### 4. Vision Report Scanner
- **Drag & Drop**: High-tech drop zone for medical images.
- **Laser Scan**: Visual scanning animation that simulates report analysis.
- **Structured Results**: Displays summary, alerts, and findings in a grid-based holographic layout.

### 5. Cinematic About Page
- **Neural Scan Splash**: A logo glitch animation that "unlocks" the dossier.
- **Video Feed HUD**: Top/bottom letterboxing with live metadata (FPS, Latency, Storage ID).
- **Motion**: Subtle Ken Burns auto-pan and zoom to create a recorded video aesthetic.

## 🛠️ Setup & Development

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```

- **Aesthetic**: Cyberpunk / Sci-Fi / Medical-Tech.
- **Colors**: Emerald (`#10b981`), Cyan (`#06b6d4`), Obsidian (`#030303`).
- **Typography**: Monospaced fonts for data, Bold Sans-serif for headings.
